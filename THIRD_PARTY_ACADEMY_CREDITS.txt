CUBE HERO ACADEMY — ALGORITHM DATA ATTRIBUTION

The 119 standard F2L (41), OLL (57), and PLL (21) primary algorithm sequences
in src/lib/academyFullCases.ts were adapted from the MIT-licensed
@moishy/algsets package, version 0.3.3, by Moshe Rosenberg.
The upstream dataset acknowledges community algorithm collections from
SpeedCubeDB and includes multiple algorithms per case. This project selects
one working representative for each case, renders the inverse-derived setup,
and provides original beginner-friendly instructional descriptions.

Package: https://jsr.io/@moishy/algsets
Source:  https://github.com/moishy-r/moishy-cubing
Algorithm reference: https://speedcubedb.com/
